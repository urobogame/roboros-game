# Roboros

Pixel snake game in a mechanical handheld-console style.

Special golden chips trigger Roboros mode: the snake keeps its first five segments, everything after the fifth segment freezes as an edible mechanical tail, and frozen segments give bonus score and extra time without increasing snake length. Pausing freezes the mode timer.

The interface uses an English pixel-style UI, the transparent `roboros_logo.png` logo, chip pickups, and a canvas-drawn metallic snake.

## Local Launch

Open `index.html` in a browser.
